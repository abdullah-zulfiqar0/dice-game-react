<h1 align="center">React Dice Game</h1>

<p align="center">
A simple and interactive dice game built with React.
This project was created to practice React fundamentals, state management, props, components, and user interactions.
</p>

<hr>

<h2>Overview</h2>

<h3>About The Project</h3>

<p>
This is a React-based dice game where the user selects a number and rolls the dice.
The score is updated depending on whether the selected number matches the dice result.
</p>

<p>The application allows users to:</p>

<ul>
<li>Select a number</li>
<li>Roll the dice by clicking on it</li>
<li>Generate a random dice number between 1 and 6</li>
<li>Increase the score when the selected number matches the dice result</li>
<li>Lose points when the selected number does not match the dice result</li>
<li>View the updated score dynamically</li>
</ul>
