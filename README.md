# React Dice Game

> A simple and interactive dice game built with React.  
> This project was created to practice React fundamentals, state management, props, components, and user interactions.

---

## Overview

### About The Project

This is a React-based dice game where the user selects a number and rolls the dice.  
The score is updated depending on whether the selected number matches the dice result.

The application allows users to:

- Select a number
- Roll the dice by clicking on it
- Generate a random dice number between 1 and 6
- Increase the score when the selected number matches the dice result
- Lose points when the selected number does not match the dice result
- View the updated score dynamically
